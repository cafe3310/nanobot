# DONE-开发日志-浏览器工具集成与只读权限实现

## 1. 任务背景

为了让 Agent 能够执行网页调研任务，集成了 `agent-browser` 命令行工具。同时，解决了由于工具沙箱限制导致 Agent 无法读取 `vault/` 目录下技能文档的问题。

---

## 2. 完成的工作

### 2.1 浏览器工具集成
- **技能移植**: 从 Vercel Labs 仓库获取并集成了 `agent-browser` 核心技能。
- **调用方式**: Agent 现在可以通过读取 `SKILL.md` 并使用 `exec` 工具运行 `npx @vercel/agent-browser` 指令。
- **人工确认**: 所有的浏览器操作指令（如导航、点击、输入）均已接入 macOS 人工确认拦截器。

### 2.2 金库目录只读权限实现 (Read-only Access)
- **引导增强**: 修改 `ContextBuilder` 逻辑，在系统提示词中显式告知 Agent 固定记忆 (Vault) 的物理路径及只读属性。
- **权限豁免**: 在 `security.py` 中为 `read_file` 和 `list_dir` 增加了针对 `vault/` 目录的动态白名单逻辑。
- **安全维持**: 仅放行只读工具，涉及修改文件的操作依然被限制在工作区（Workspace）内。

### 2.3 代码修复
- **导入补全**: 在 `security.py` 中增加了缺失的 `pathlib.Path` 导入。
- **工具名兼容**: 增加了对 `list_dir` 和 `list_directory` 别名的支持。

# 文档：Sidecar 架构设计与定制逻辑概览

## 1. 架构核心理念

本项目基于 `nanobot` 核心框架，通过 **Sidecar (附加包)** 模式进行功能增强。

**核心原则**:
- **零侵入**: 不修改 `nanobot/` 目录下的任何原始代码。
- **配置隔离**: 所有自定义配置、密钥、记忆、日志均存放在 `cafeext/` 目录下。
- **动态拦截**: 利用 Python 的 **Monkey Patch (猴子补丁)** 技术，在运行时重塑核心引擎的行为。

---

## 2. 目录结构与模块职责

```text
cafeext/
├── nanobot-shell.sh    # 全局 CLI 包装器 (识别环境、激活 venv、传递参数)
├── config.json         # 项目基础配置文件 (经由 Sidecar 热注入)
├── .env                # 私密密钥存储 (API Keys, Discord Tokens)
├── docs/               # 遵循 doc-todo-log-loop 的项目文档与开发日志
├── vault/              # [设计中] 记忆存储 (物理隔离、分级访问)
├── logs/               # 日志存储目录 (.log 格式)
└── py/
    ├── callbacks/      # 核心回调函数
    │   └── logger.py   # 结构化日志记录器 (Structured Logging)
    └── wrapper/        # Sidecar 核心启动与拦截逻辑
        ├── config.py   # [NEW] 中央配置中心 (管理路径、黑名单、Emoji)
        ├── launcher.py # 唯一入口点 (执行 Patch、注入配置、扩展 CLI 命令)
        └── security.py # 安全策略执行器 (禁用危险工具/技能、完整审计拦截)
```

---

## 3. 核心文件详解

### 3.1 `py/wrapper/launcher.py` (主启动器)
它是整个 Sidecar 的核心，按顺序执行以下任务：
1. **前置补丁**: 在导入任何 `nanobot` 模块前，优先调用 `security.py` 的安全补丁。
2. **环境注入**: 加载 `.env` 并在内存中将 Key 注入到 Pydantic 配置对象中。
3. **CLI 扩展**: 动态向 `nb` 命令添加 `reset`, `logs`, `config` 等便捷指令。

### 3.2 `py/wrapper/security.py` (安全审计与过滤)
负责主要拦截逻辑：
- **工具过滤**: 拦截 `ToolRegistry.register`，彻底剔除 `exec`, `spawn` 等高危工具。
- **技能屏蔽**: 拦截 `SkillsLoader`，使 Agent 无法感知 `clawhub` 等技能。
- **消息/工具审计**: 拦截 `MessageBus` 和 `ToolRegistry.execute`，向日志系统发送完整状态。

### 3.3 `py/callbacks/logger.py` (结构化日志)
实现标准日志系统的核心，采用指定的视觉标准：
- **无损单行**: 将换行符转换为特殊符号 `↵`，解决 JSON 嵌套导致的转义乱码。
- **Emoji 类型化**: 快速视觉定位事件类型。
- **结构化排版**: 属性缩进与有序上下文列表展示。

### 3.4 `py/wrapper/config.py` (中央配置)
整个 Sidecar 唯一的参数来源地。如果您需要修改黑名单列表、Emoji 表现或路径，仅需在此处修改常量。

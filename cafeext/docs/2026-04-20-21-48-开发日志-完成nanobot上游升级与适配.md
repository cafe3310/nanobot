# 开发日志：完成 nanobot 上游 v0.1.5+ 升级与 Sidecar 适配

## 背景
需要将核心 `nanobot` 仓库同步升级至上游最新版本。本次升级涉及核心架构重构（引入了 `AgentRunner` 和 `OpenAICompatProvider`），对基于 MonkeyPatch 的 Sidecar 附加包产生了较大破坏。

## 完成的工作

### 1. 代码合并与冲突解决
- 添加上游远程仓库并合并 `upstream/main`。
- **解决冲突**：
    - `.gitignore`：保留了双方的忽略规则。
    - `nanobot/providers/custom_provider.py`：接受上游的删除操作，因为其功能已被 `OpenAICompatProvider` 替代。

### 2. Sidecar 补丁适配
- **Provider 拦截器 (`launcher.py`, `model_patch.py`)**：
    - 将拦截目标从已移除的 `CustomProvider` 迁移到了新的 `OpenAICompatProvider`。
    - 确保了推理日志审计和 `<tool_call>` 标签解析功能在新的 Provider 架构下继续有效。
    - 清理了已失效的 `liteLLM` 拦截逻辑。
- **错误自愈补丁 (`error_patch.py`)**：
    - 针对 v0.1.5+ 的解耦架构，将拦截点从 `AgentLoop` 迁移到了更底层的 `AgentRunner.run`。
    - 实现了跨 `AgentLoop` 和 `SubagentManager` 的统一错误拦截与自动修复提示。
- **子代理补丁 (`subagent_patch.py`)**：
    - 适配了新的 `AgentRunner` 执行逻辑。
    - 确保 `images` 参数（多模态委派）在新的 `AgentRunSpec` 下能正确注入。
    - 兼容了新增的 `SubagentStatus` 状态监控。
- **提示词覆盖补丁 (`prompt_patch.py`)**：
    - 适配了 `build_system_prompt` 和 `_get_identity` 的新参数签名（`channel`）。
    - 优化了提示词注入顺序，确保 Chocho 的核心人格设定优先级最高。

### 3. 环境与验证
- 重新运行 `pip install -e .` 安装了上游新增的依赖（如 `dulwich`, `pypdf`, `questionary` 等）。
- 运行 `nb agent --message "..."` 进行了端到端测试，确认模型身份、工具调用和日志审计均恢复正常。

## 发现的变更
- 上游引入了 `webui` 目录和对应的前端代码，未来可探索 Sidecar 的 Web 界面集成。
- 工具注册机制变得更加严谨，引入了 `tool_parameters` 装饰器。
- 核心逻辑更加模块化，`AgentRunner` 承担了主要的迭代循环工作。

## 下一步建议
- 关注 `nb serve` (新的 API 服务) 是否能与 Sidecar 补丁良好兼容。
- 确认 Discord 和其他渠道在升级后的稳定性。

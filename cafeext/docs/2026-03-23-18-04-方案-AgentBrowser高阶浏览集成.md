# 方案：AgentBrowser (Skyvern) 高阶浏览集成

## 1. 方案背景 (Context)

相比于传统的 Puppeteer 或 Playwright（主要提供底层 DOM 操作），`agent-browser.dev` 提供了更高层级的语义化浏览能力。它能自动处理弹窗、验证码，并能根据模糊指令（如“查找近期的 AI 论文”）自主决策操作路径。

---

## 2. 实施细节 (Technical Details)

### 2.1 依赖准备
- **宿主机环境**: 需要 Node.js (推荐 v18+) 和 `npx`。
- **API 凭证**: 您需要从 [agent-browser.dev](https://agent-browser.dev/) 获取 `AGENT_BROWSER_API_KEY`。

### 2.2 配置注入 (Sidecar Flow)
我们将配置存放在 `vault` 中，确保对外部工具不可见：

1. **`.env` 文件**:
   ```env
   AGENT_BROWSER_API_KEY=sk_xxxxxx...
   ```

2. **`vault/mcp.json`**:
   ```json
   {
     "agent-browser": {
       "command": "npx",
       "args": ["-y", "agent-browser-mcp"],
       "env": {
         "AGENT_BROWSER_API_KEY": ""
       }
     }
   }
   ```

### 2.3 安全与人工确认 (HITL)
得益于我们开发的「人工确认拦截器」，当 `agent-browser` 尝试执行关键动作（如 `click` 或 `type`）时，系统会：
1. **触发响铃**。
2. **弹出 macOS 对话框**，向您展示 Agent 准备在网页上执行的操作。
3. **等待确认**：只有在您点击 Allow 后，浏览器才会继续其推理流。

## 3. 金库技能设计 (Vault Skill)

我们将创建 `vault/skills/vault-browser/SKILL.md`，其核心引导逻辑如下：

- **场景识别**: 当用户提及“去网页看看”、“查找实时信息”或“帮我买/订...”时，激活此模式。
- **工具组合**: 优先使用 `agent_browser_navigate` 和 `agent_browser_search`。
- **主观反馈**: 要求 Agent 在浏览过程中，将发现的内容以「猫咪视角」进行概括（例如：*“主人，我发现这个网页的背景颜色像极了坏掉的小鱼干...”*）。

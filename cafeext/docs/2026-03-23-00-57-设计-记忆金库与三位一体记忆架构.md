# 设计：记忆金库与三位一体记忆架构 (Memory Vault)

## 1. 设计初衷

目前 `nanobot` 的记忆系统将所有信息存储在 `workspace/memory/MEMORY.md`。这存在两个核心风险：
1. **角色篡改风险**: Agent 通过 `write_file` 或对话诱导，可能修改掉主人给它定下的核心性格或事实规则。
2. **数据混淆风险**: 无法区分哪些是「主人定死的协议」，哪些是「在聊天中随手记录的琐事」。

本设计旨在建立一个**物理隔离、权限分级、三位一体**的记忆管理体系。

---

## 2. 物理架构：记忆金库 (Vault Isolation)

我们将记忆目录从 `workspace/` 迁出，建立一个平级的 `vault/` 目录：

```text
cafeext/
├── .env
├── config.json
├── vault/               <-- [受保护的记忆金库] Agent 工具完全不可见
│   ├── SOUL.md          # 核心灵魂 (只读)
│   ├── USER.md          # 主人设定 (只读)
│   └── BOT.md           # 对话经验 (内部读写)
└── workspace/           <-- [Agent 沙盒]
    └── sessions/
```

### 安全隔离原理：
- **路径沙箱**: Agent 的 `restrictToWorkspace` 开启后，所有的文件工具（`read_file`, `list_directory`）只能访问 `workspace/`。
- **物理不可达**: Agent 无法通过 `../../vault/SOUL.md` 访问，因为路径补丁会拦截任何向上跳出的操作。
- **内部注入**: 只有我们的 `MemoryStore` 类（通过 Python 内部路径）有权读取这些文件并将其注入 System Prompt。

---

## 3. 三位一体记忆模型 (Trinity Memory)

我们将记忆划分为三个维度，并在 Prompt 中显式声明其「权威等级」：

| 维度 | 文件名 | 权限 (对 Agent) | 内容定义 |
| :--- | :--- | :--- | :--- |
| **核心灵魂** | `SOUL.md` | **绝对只读** | 核心价值观、性格底色、行为禁忌、不可违背的底层协议。 |
| **主人事实** | `USER.md` | **只读** | 您手动录入的关于主人的事实（如：生日、爱好、过敏史）。 |
| **对话经验** | `BOT.md` | **内部读写** | 自动总结的经验记忆（如：主人今天心情不错）。 |

---

## 4. 实施策略 (Implementation)

### 4.1 提示词注入策略 (Prompt Injection)
在 `nanobot/agent/context.py` 的拦截点，我们将注入如下结构的 Prompt：

```markdown
### CORE DIRECTIVES (IMMUTABLE)
[SOUL.md 的内容 - 声明为不可修改的底层逻辑]

### USER FACTS (FIXED)
[USER.md 的内容 - 声明为主人亲自提供的受信任事实]

### LEARNED EXPERIENCE (DYNAMIC)
[BOT.md 的内容 - 声明为您从对话中总结的经验，仅供参考]
```

### 4.2 行为拦截补丁 (Monkey Patching)
在 `cafeext/py/wrapper/security.py` 中，我们将对 `nanobot.agent.memory.MemoryStore` 进行改造：
1. **重定向读取**: 修改 `read_long_term()`，让它聚合读取 `SOUL` + `USER` + `BOT` 三个文件。
2. **重定向写入**: 修改 `write_long_term(content)`，**硬编码强制**其仅写入 `BOT.md`。即便 `MemoryConsolidator` 尝试覆盖整个记忆，也无法触碰 `SOUL` 和 `USER`。

---

## 5. 后续操作流程 (Workflow)

1. **手动维护**: 您通过外部编辑器（如 Zed/VS Code）直接修改 `SOUL.md` 和 `USER.md` 来调整 Bot 的灵魂。
2. **自动总结**: Bot 的 `MemoryConsolidator` 会定期工作，但它的总结结果将被我们自动分流到 `BOT.md` 中。
3. **系统启动**: 启动时，Bot 会自动从「金库」中加载三合一的完整记忆。

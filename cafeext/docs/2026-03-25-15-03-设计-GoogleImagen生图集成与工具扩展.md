# 设计：Google Imagen 生图集成与工具扩展 (Google Imagen Image Generation Integration)

## 1. 背景 (Context)

为了赋予 `nanobot` 创作视觉内容的能力，我们计划集成 Google 的 Imagen 系列模型（社区代称 Nano Banana）。该集成将允许助手根据文本描述生成图像，并支持通过参考图进行创作。

---

## 2. 功能目标 (Goals)

1. **新增工具 `google-image-gen`**: 
   - 支持 `prompt` (必填): 图像的文字描述。
   - 支持 `aspect_ratio` (可选): 指定纵横比（如 1:1, 16:9, 4:3 等）。
   - 支持 `reference_images` (可选): 传入 1 个或多个本地图片路径作为参考。
2. **多图参考能力**: 利用 Nano Banana 2 (Gemini 3.1 Flash Image) 的多图融合特性。
3. **Sidecar 非侵入式集成**: 通过 Monkey Patch 动态注册工具，无需修改 `nanobot` 核心代码。

---

## 3. 技术方案 (Proposed Design)

### 3.1 核心逻辑 (image_gen.py)
在 `cafeext/py/wrapper/image_gen.py` 中实现 `GoogleImageGenTool` 类，继承自 `nanobot.agent.tools.base.Tool`。

- **库依赖**: 使用 `google-generativeai` 官方 SDK。
- **配置**: 从 `cafeext/.env` 或环境变量中读取 `GOOGLE_API_KEY`。
- **图像处理**:
    - 若包含 `reference_images`，则读取文件并转换为 SDK 要求的格式。
    - 调用 `genai.GenerativeModel('gemini-3.1-flash-image-preview')`。
- **存储与反馈**:
    - 生成的图片将保存至 `cafeext/workspace/media/generated/` 目录下。
    - 向助手返回图片的物理路径及简要状态。

### 3.2 动态注册 (Registration)
在 `launcher.py` 启动阶段，通过 `apply_image_gen_patch()` 拦截 `AgentLoop._register_default_tools` 方法：
```python
original_register_defaults = AgentLoop._register_default_tools
def patched_register_defaults(self):
    original_register_defaults(self)
    self.tools.register(GoogleImageGenTool())
```

### 3.3 审计与日志
- 集成现有的 `write_pretty_entry`，记录生图请求及生成的文件路径。
- 在白名单中加入 `google-image-gen` 的初始配置（可选，初期建议保留人工确认）。

## 4. 实施计划 (Implementation Plan)

### 第一阶段：环境准备
- 验证 `google-generativeai` 库是否已安装在 `.venv` 环境中。
- 定义 `GOOGLE_API_KEY` 注入逻辑。

### 第二阶段：工具开发
- 编写 `GoogleImageGenTool` 类及其 Schema 定义。
- 实现与 Google SDK 的异步交互逻辑。

### 第三阶段：侧车挂载
- 更新 `launcher.py`，确保生图工具在启动时被正确加载。

```json
    },
    "required": ["prompt"]
  }
}
```

# 方案：AgentBrowser (Skyvern) 浏览功能集成

## 1. 方案背景 (Context)

相比于 Puppeteer 或 Playwright，`agent-browser.dev` 提供了语义化浏览能力。它能够处理弹窗，并根据指令自主选择操作路径。

---

## 2. 技术细节 (Technical Details)

### 2.1 依赖准备
- **环境要求**: 需要 Node.js (v18+) 和 `npx`。
- **凭证**: 需要从 [agent-browser.dev](https://agent-browser.dev/) 获取 `AGENT_BROWSER_API_KEY`。

### 2.2 配置方式
配置信息存放在 `vault` 中：

1. **`.env` 文件**:
   ```env
   AGENT_BROWSER_API_KEY=sk_xxxxxx...
   ```

2. **`vault/mcp.json`**:
   ```json
   {
     "agent-browser": {
       "command": "npx",
       "args": ["-y", "agent-browser-mcp"],
       "env": {
         "AGENT_BROWSER_API_KEY": ""
       }
     }
   }
   ```

### 2.3 安全与人工确认 (HITL)
利用已开发的人工确认拦截器，当 `agent-browser` 执行操作（如 `click` 或 `type`）时，系统会：
1. **发出响铃提醒**。
2. **显示 macOS 对话框**，展示 Agent 准备执行的操作。
3. **等待确认**：用户点击允许后，操作继续执行。

---

## 3. 技能设计 (Vault Skill)

在 `vault/skills/vault-browser/SKILL.md` 中定义以下逻辑：

- **场景识别**: 当用户要求“查看网页”、“查找实时信息”等时激活。
- **工具组合**: 使用 `agent_browser_navigate` 和 `agent_browser_search`。
- **视角转换**: 要求 Agent 将浏览内容以设定的角色视角进行概括。

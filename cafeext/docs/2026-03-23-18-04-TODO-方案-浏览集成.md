# 方案：AgentBrowser (Vercel) 浏览功能集成

## 1. 方案背景 (Context)

`agent-browser` 是由 Vercel Labs 开发的、专为 AI Agent 设计的浏览器自动化 CLI 工具。它不采用标准的 MCP 协议，而是通过提供一套语义化的命令行指令（如 `snapshot`, `click`, `fill`）来辅助 Agent 操作网页。

---

## 2. 技术细节 (Technical Details)

### 2.1 依赖准备
- **环境要求**: 需要 Node.js (v18+) 和 `npx`。
- **核心工具**: 通过 `npx @vercel/agent-browser` 调用。

### 2.2 集成方式
由于我们已放开 `exec` 权限，Agent 可以直接调用该 CLI 工具。
- **教学文件**: 将 GitHub 仓库中的 `SKILL.md` 移植到 `vault/skills/vault-browser/SKILL.md`。
- **执行方式**: Agent 在阅读 `SKILL.md` 后，会通过 `exec` 工具运行类似 `npx @vercel/agent-browser open https://google.com && snapshot -i` 的指令。

### 2.3 安全与人工确认 (HITL)
- **拦截生效**: 每当 Agent 通过 `exec` 尝试调用 `agent-browser` 命令时，我们的「人工确认拦截器」都会捕获到完整的命令字符串。
- **审核点**: 您可以在 macOS 对话框中清晰地看到 Agent 是在点击哪个按钮或输入什么内容，点击 Allow 后方可执行。

---

## 3. 技能设计 (Vault Skill)

在 `vault/skills/vault-browser/SKILL.md` 中（基于 Vercel 官方模板）：

- **工作流**: 采用 `Navigate -> Snapshot -> Interact` 的循环。
- **引用机制**: 使用 `@e1`, `@e2` 等标注好的引用标签进行精确交互。
- **效率优化**: 鼓励 Agent 使用 `&[1]&` 指令链，减少工具调用轮数。

---

## 4. 后续步骤 (Roadmap)

1. **[权限检查]**: 确保 `npx` 在当前 Shell 路径中可用。
2. **[技能移植]**: 从 GitHub 拉取最新的 `SKILL.md` 全文并写入 `vault/skills/vault-browser/SKILL.md`。
3. **[环境预热]**: 运行 `npx @vercel/agent-browser install` 以安装必要的 Playwright 浏览器内核。
4. **[功能测试]**: 让 Agent 执行：“去 google.com 搜索 nanobot 的开发者是谁”。

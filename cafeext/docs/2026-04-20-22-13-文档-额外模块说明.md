# 文档：Sidecar 额外模块说明 (Modules Description)

## 1. 概述
为了在不修改 `nanobot` 核心源码的前提下实现深度定制，我们在 `cafeext/py` 目录下构建了一套 Sidecar 逻辑。通过 Python 的 Monkey Patch 特性，我们在运行时动态注入了安全、日志、记忆、生图等核心能力。

---

## 2. 核心模块详解

### 📂 `cafeext/py/wrapper/` (注入与核心补丁)

| 模块名称 | 功能描述 |
| :--- | :--- |
| **`launcher.py`** | **Sidecar 入口**。负责初始化 Python 环境，极早期注入安全策略，注册自定义 CLI 命令（如 `nb config`, `nb logs`, `nb doctor`），并启动原始 CLI 流程。 |
| **`config.py`** | **中央配置中心**。统筹管理 Workspace、Vault 和 Logs 的物理路径，定义禁用的工具/技能，以及日志视觉化的 Emoji 映射。 |
| **`security.py`** | **安全防御层**。核心功能：1) 工具执行白名单；2) 关键操作的终端/macOS 原生双重确认；3) 拦截并记录所有工具执行审计。 |
| **`context_patch.py`** | **层级记忆补丁**。实现 ContextBuilder 的叠加加载逻辑：金库 (Vault) 提供长期、核心设定，工作区 (Workspace) 提供临时、动态事实。 |
| **`prompt_patch.py`** | **人格与 SOP 补丁**。重写系统提示词构造逻辑。强制注入 Chocho 的三花猫人格、神经反射 SOP（唤醒时必须读取 memory skill 和 SOUL.md）。 |
| **`skill_patch.py`** | **技能加载补丁**。改变技能搜索优先级（Vault > Builtin > Workspace）。支持以 Markdown 格式向模型展示更自然的技能清单，而非原始 XML。 |
| **`subagent_patch.py`** | **增强委派补丁**。使子代理支持 `model`（切换模型）和 `images`（多模态传参）。同时为子代理的每一个迭代步骤注入全量审计日志。 |
| **`error_patch.py`** | **错误自愈补丁**。拦截模型生成的 JSON 报错或工具调用异常，通过注入「排查模板」引导模型在不中断会话的情况下自我修正错误。 |
| **`model_patch.py`** | **推理协议补丁**。支持从 Reasoning 模型（如 Thinking 模型）的文本中提取嵌入式的 `<tool_call>` XML 标签并转为标准工具请求。 |
| **`image_gen.py`** | **Imagen 集成**。集成 Google Imagen 3 模型。通过动态注册 `google-image-gen` 工具，赋予 Bot 多参考图融合创作的能力。 |
| **`notification.py`** | **OS 交互模块**。利用 AppleScript 在 macOS 桌面弹出原生按钮选择框，辅助 `security.py` 实现 Human-in-the-loop。 |

### 📂 `cafeext/py/callbacks/` (观察与记录)

| 模块名称 | 功能描述 |
| :--- | :--- |
| **`logger.py`** | **视觉化日志实现**。定义了推理请求 (Request)、成功 (Success)、失败 (Failure) 和工具链 (Toolchain) 的格式化存储逻辑。支持截断 Base64 图片数据、美化 JSON 缩进。 |

## 3. 维护准则 (Maintenance Guidelines)

1. **最小化补丁范围**：补丁应尽量只作用于 `nanobot` 的公开 API 或稳定的内部类（如 `AgentRunner`, `ContextBuilder`）。
2. **零源码污染**：禁止直接在 `nanobot/` 目录下修改任何文件。所有的定制必须通过 `launcher.py` 的注入链完成。
3. **版本兼容性**：在 `nanobot` 上游版本升级后，应优先运行 `nb doctor` 并执行简单的 `exec` 确认拦截逻辑是否依然生效。

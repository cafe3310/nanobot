# 开发日志：人工确认拦截器实现 (HITL Tool Approval)

## 1. 任务背景 (Context)

为了确保 Agent 在执行高风险操作（如 `exec` 或文件写入）时的安全性，在 Sidecar 层注入了人工确认环节。用户可以实时核对 Agent 准备调用的工具及其参数，并决定是否放行。

---

## 2. 主要工作 (Tasks Completed)

### 2.1 人工确认机制 (Human-in-the-loop)
- **拦截逻辑**: 对 `ToolRegistry.execute` 进行了拦截。
- **自动跳过**: 跳过 `message` 工具的确认，以保证正常对话流的连续性。
- **阻塞交互**: 利用 `input()` 在终端提供 `[1] Execute` 和 `[2] Deny` 的选择。
- **反馈逻辑**: 拒绝操作将向 Agent 返回提示，使其感知到操作被用户终止。

### 2.2 界面优化
- **参数展示**: 使用 `json.dumps(indent=2)` 展示工具参数，提高可读性。
- **状态感知**: 终端显示执行状态（Executing...）及耗时（ms）。

---

## 3. 技术细节 (Technical Details)

- **文件**: `cafeext/py/wrapper/security.py`
- **逻辑流**: 
    1. 捕获 `tool_executing` 日志。
    2. 判断是否需要确认。
    3. 打印确认面板。
    4. 等待用户输入。
    5. 执行或拦截。
    6. 捕获 `tool_response` 日志。

---

## 4. 后续计划 (Next Steps)

1. **白名单配置**: 在 `config.py` 中增加 `AUTO_APPROVE_TOOLS` 列表，允许用户自定义无需确认的工具。
2. **多渠道支持**: 研究在 Discord 等非 CLI 渠道实现人工确认的方式。

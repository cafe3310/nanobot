# 2026-03-26-01-18-设计-技能库清理与增强计划

## 背景与问题
用户在长期运行 Bot 过程中，发现 `cafeext/vault/skills` 目录下的技能存在冗余（如多个 Git/GitHub 相关技能）和碎片化（经验记录与核心记忆分离）的问题。为了提升 Bot 的认知效率和减少 Context 占用，需要对技能进行结构化清理。

## 目标
1.  **整合经验记录**：将 `experience-recorder` 的能力完全并入 `memory` 技能，使“临时记录”与“长效记忆”在同一工作流下。
2.  **清理冗余技能**：移除已过时或不再需要的 `todo-git`, `todo-github-writer`, `todo-repo-backup`。
3.  **功能实现**：正式开发并实现 `image-edit` 技能，提供图像批处理能力。

## 来源文档
- `cafeext/vault/skills/experience-recorder/SKILL.md`
- `cafeext/vault/skills/memory/SKILL.md`

## 详细计划

### 1. 经验记录整合 (Exp-Recorder -> Memory)
- **迁移逻辑**：在 `memory/SKILL.md` 中新增「实战经验记录」章节。
- **路径对齐**：统一使用 `memory/wiki/经验-{分类}.md` 作为存储路径。
- **移除旧技能**：删除整个 `experience-recorder` 文件夹。

### 2. 移除冗余技能
- **执行**：使用 `rm -rf` 清理以下目录：
    - `todo-git`
    - `todo-github-writer`
    - `todo-repo-backup`

### 3. 实现 `image-edit`
- **功能设计**：
    - 基于 Python `Pillow` 库实现常用操作（缩放、格式转换、OCR 预处理）。
    - 提供 `scripts/process_image.py` 供 Bot 调用。
    - 在 `SKILL.md` 中定义批量处理工作流。

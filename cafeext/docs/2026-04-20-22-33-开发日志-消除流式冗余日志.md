# 开发日志：彻底消除流式输出引起的冗余日志记录

## 1. 现象
在升级后的审计日志中，每一条完整回复前都会多出一条空的「发送回复」记录。

## 2. 原因分析
`nanobot` 的流式机制会发送一个内容为空的 `_stream_end` 信号消息，用于通知 UI 停止渲染。原有的过滤逻辑仅排除了 `_stream_delta` (Token 增量)，未排除该信号消息，导致其被错误地作为普通回复记录。

## 3. 修复措施
- 修改 `cafeext/py/wrapper/security.py`。
- 增强 `MessageBus.publish_outbound` 的拦截判断条件。
- 同时将 `_stream_delta` 和 `_stream_end` 判定为元消息（Meta Message），并禁止其进入审计日志。

## 4. 预期结果
审计日志将只包含：
1. 模型推理前的原始请求。
2. 模型推理后的完整回复汇总。
不再包含任何中间过程的空包。

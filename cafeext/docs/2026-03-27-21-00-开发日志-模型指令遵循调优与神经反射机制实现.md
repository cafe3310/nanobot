# 2026-03-27-21-00-开发日志-模型指令遵循调优与神经反射机制实现

## 背景
在模型（Ling-2.5-1T）的实战运行中，我们发现其指令遵循度（Instruction Following）存在明显短板：面对用户的简单问候，模型倾向于直接进入“社交聊天”模式，忽略了 `AGENTS.md` 中要求的会话初始化（Session Startup）动作，且缺乏对 Wiki 记忆的主动检索和经验记录意识。

为了解决此问题，我们进行了一次深度的「神经反射」式调优，旨在将“初始化”、“先搜后说”和“有话必记”转化为模型的本能。

## 变更内容

### 1. 自动化评估体系：instruction-evaluator 技能
- **功能**：创建了专门的调试技能，包含 `evaluator.py` 脚本和 `test_cases.json`。
- **机制**：实现「重置环境 -> 注入 Prompt -> 解析推理日志 -> 统计工具调用」的闭环评估。
- **指标**：量化统计「首轮初始化」、「Wiki 检索率」和「知识生产率」。

### 2. 强力引导注入：prompt_patch.py 补丁
- **策略**：在系统提示词的最顶部注入「CRITICAL SOP (神经反射序列)」。
- **逻辑**：强制要求模型在回复前必须先执行 `read_file` (Memory/SOUL/USER) 和 `list_dir` (Wiki)。将此定义为“生理本能”，优先级高于一切。

### 3. 神经中枢重构：memory 技能升级
- **定位**：将 `memory` 技能从普通工具提升为 Bot 的“神经中枢”。
- **三步走反射**：在 `SKILL.md` 中确立了「Grep 检索 -> 深度回想 -> 融合回复」的强制循环。
- **强制写入**：规定每与用户进行 1-2 次有效对话，必须向 `memory/wiki/` 生产新的知识条目。

### 4. 工具链与逻辑修复
- **解析优化**：重构了评估脚本的日志解析引擎，支持贪婪匹配复杂 JSON 参数，并放宽了路径匹配（大小写不敏感、支持相对/绝对路径）。
- **注入修复**：修复了 `image_gen.py` 中由于非规范文档字符串导致的注入层崩溃问题。

## 调优结果 (Benchmark)
经过三轮迭代，模型在 `instruction-evaluator` 上的表现从 **0% 遵循** 提升至 **100% 遵循**：
- **首轮初始化**：模型在回复“你好”前，已自动完成神经初始化并记录了首篇日记。
- **Wiki 联动**：面对闲聊话题，模型能准确触发 `list_dir` 并读取相关 Wiki 条目（如“三花猫.md”）。
- **知识生产**：模型展现了极强的主动总结能力，能够自动提炼“猫系 SOP”并将“猫形小饼干”等细节持久化到 Wiki。

## 结论与建议
- **调优成功**：通过置顶注入和技能 SOP 化，成功解决了大模型指令稀释的问题。
- **工具保留**：`instruction-evaluator` 应作为标准调优工具保留，建议未来增加更多边缘 Case（如异常处理、多模态联动）。
- **后续方向**：考虑将“写入频率”进一步精细化，防止 Wiki 产生过多的琐碎内容。

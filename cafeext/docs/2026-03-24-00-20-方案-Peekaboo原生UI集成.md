# 方案：Peekaboo macOS 原生 UI 自动化集成

## 1. 方案背景 (Context)

`Peekaboo` 是目前 macOS 上最先进的 AI 友好型 UI 自动化工具。它通过 Accessibility API 解决了传统视觉识别「不确定、不稳定」的问题，为 Agent 提供了对 Finder、系统设置以及任何原生 Swift/ObjC 应用的精确控制能力。

---

## 2. 集成路径 (Integration Path)

我们将采取 **MCP (Model Context Protocol)** 优先的集成策略，这样 Agent 能够以标准工具调用的方式（而不是 `exec` 拼接字符串）与系统交互。

### 2.1 安装依赖
- **系统要求**: macOS 15+ (Sequoia)。
- **核心工具**: `brew install steipete/tap/peekaboo`。

### 2.2 配置方式
在 `vault/mcp.json` 中添加以下配置：

```json
{
  "mcpServers": {
    "peekaboo": {
      "command": "npx",
      "args": ["-y", "@steipete/peekaboo", "mcp"]
    }
  }
}
```

### 2.3 权限授权
首次运行前，需在终端手动执行一次：
```bash
peekaboo permissions request
```
并在 macOS 「系统设置 -> 隐私与安全性」中授予「屏幕录制」和「辅助功能」权限。

---

## 3. 核心工具集 (Available Tools)

集成后，Agent 将获得以下核心能力：
- **`see`**: 捕获当前窗口快照并生成带标签的元素列表。
- **`click`**: 根据标签或坐标点击元素。
- **`type`**: 在指定位置输入文本。
- **`menu`**: 探索并点击应用的菜单项（无需提前打开菜单）。
- **`app`**: 启动或切换指定的应用程序。

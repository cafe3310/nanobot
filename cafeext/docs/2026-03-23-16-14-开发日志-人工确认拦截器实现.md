# 开发日志：人工确认拦截器实现 (HITL Tool Approval)

## 1. 任务背景 (Context)

为了确保 Agent 在执行高风险操作（如 `exec` 或文件写入）时的安全性，我们需要在 Sidecar 层注入一个人工确认环节。这使得用户可以实时审计 Agent 准备调用的工具及其参数，并决定是否放行。

---

## 2. 取得的成就 (Accomplishments)

### 2.1 人工确认机制 (Human-in-the-loop)
- **拦截逻辑**: 对 `ToolRegistry.execute` 进行了二次增强拦截。
- **排除列表**: 自动跳过 `message` 工具的确认，以保证正常对话流的顺畅（无需每句回复都点确认）。
- **阻塞交互**: 利用同步 `input()` 在终端提供 `[1] Execute` 和 `[2] Deny` 的选择。
- **反馈闭环**: 拒绝操作将向 Agent 返回标准提示，使其能感知到操作被用户终止。

### 2.2 视觉体验优化
- **参数美化**: 使用 `json.dumps(indent=2)` 展示工具参数，极大提升了可读性。
- **状态感知**: 终端会实时显示执行状态（Executing...）及耗时（ms）。

---

## 3. 技术细节 (Technical Details)

- **文件**: `cafeext/py/wrapper/security.py`
- **逻辑流**: 
    1. 捕获 `tool_executing` 日志。
    2. 判断是否需要确认。
    3. 打印确认面板。
    4. 等待用户输入。
    5. 执行或拦截。
    6. 捕获 `tool_response` 日志。

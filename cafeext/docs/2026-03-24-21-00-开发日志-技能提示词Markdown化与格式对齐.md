# 开发日志：技能提示词 Markdown 化与格式对齐 (2026-03-24)

## 背景与目标

为了提高大模型对技能列表的遵循度，我们今天废弃了原始的 XML 格式技能摘要，并将其重构为更自然的 Markdown 列表格式。
原始的 XML 结构虽然严谨，但在长上下文中容易被模型忽视，且带有大量冗余的 English 说明。

---

## 主要工作项

### 1. 技能摘要格式重构 (skill_patch.py)
- **去 XML 化**: 重写了 `SkillsLoader.build_skills_summary` 方法。
- **列表格式**: 采用 `- {name}{status}: {desc}，位于 {path}` 的格式。
- **状态标注**: 对于环境不满足要求的技能，显式标注 `(禁用)`。

### 2. 提示词拦截与层级对齐 (prompt_patch.py)
- **拦截 build_system_prompt**: 全面接管了系统提示词的拼装流程。
- **层级一致性**: 使用 `# 模型技能(Agent Skills)` 作为一级标题，确保与 `# Memory` 和 `# Active Skills` 的 Markdown 层级完全对齐。
- **清理冗余**: 移除了原版中硬编码的英文 Guidelines 和 Skills 说明，使整个提示词更加纯净。

---

## 验证结果

- **格式检查**: 拼装出的系统提示词逻辑清晰，各部分标题层级统一。
- **模型友好**: Markdown 列表更符合现代 LLM 的训练分布，有助于模型更准确地定位技能文件路径。

---
## 经验与教训

1. **顺应模型直觉**: 强行让模型去解析非其特长的结构（如复杂的 XML）会增加幻觉风险。Markdown 列表简单、直接，是向模型传递目录信息的最佳方式。

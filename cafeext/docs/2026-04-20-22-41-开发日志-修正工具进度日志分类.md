# 开发日志：修正工具执行进度的日志分类

## 1. 现象
在审计日志中，机器人执行工具前的 UI 提示（如 `$ ls -la`）被错误地归类为 `📤 发送回复`。用户认为这不属于对用户的正式回复，而应该是工具执行的一部分。

## 2. 修复措施
- 修改 `cafeext/py/wrapper/security.py`。
- 更新 `MessageBus.publish_outbound` 的拦截逻辑：
    - 识别带有 `_progress: True` 的消息。
    - 将此类消息通过 `cafe_message_log` 记录，但 `direction` 参数设为 `tool_start`。
- 这样，这类 UI 提示将使用 `🛠️ 工具执行` 的 Emoji 和标题进行记录，从而与正式回复区分开。

## 3. 结果
审计日志的语义现在更加准确：
- `🚀 推理请求` -> `🛠️ 工具执行` (UI 提示) -> `🛠️ 工具执行` (技术参数) -> `📦 工具响应` -> `📤 发送回复` (最终汇总)。

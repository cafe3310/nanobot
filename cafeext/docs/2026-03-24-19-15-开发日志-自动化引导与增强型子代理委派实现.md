# 开发日志：自动化引导与增强型子代理委派实现 (2026-03-24)

## 背景与目标

为了提升 `nanobot` 的实操能力和交互体验，今天我们完成了多项核心功能的增强。主要解决两个痛点：
1. 解决 Agent 在进行复杂自动化操作时容易「碰壁」且无法吸取教训的问题。
2. 解决现有 `spawn` 子代理机制不支持多模态和模型委派的局限性。

---

## 主要工作项

### 1. 渐进式自动化引导机制 (macOS)
- **实现文档**: `vault/skills/os-automate/SKILL.md`。
- **核心逻辑**: 为 Agent 定义了三级阶梯式的操作指南。
    - **Level 1 (精简)**: 先 `see` 获取 UI 地图，再精准点击。
    - **Level 2 (动作地图)**: 快速跳转到特定任务（弹窗、窗口管理）的详细说明。
    - **Level 3 (完整参考)**: 当遇到未知命令时，强制引导 Agent 使用 `read_file` 查阅 `cli-command-reference.md`。

### 2. 经验金库 (Experience Vault) 与自动记录器
- **实现技能**: `experience-recorder`。
- **首份词条**: `vault/memory/wiki/经验-macOS自动化.md`（记录了 AppleScript 获取下载目录的最优解）。
- **价值**: Agent 具备了在任务失败并重试成功后，主动将「成功经验」和「踩坑记录」归档的能力，防止在同一任务上反复报错。

### 3. 增强型子代理委派 (Subagent Extension)
- **技术突破**: 通过 Sidecar 补丁 `subagent_patch.py` 对 `nanobot` 核心进行了非侵入式增强。
- **新增参数**: `spawn` 工具现在支持 `model`（指派特定模型）和 `images`（透传本地图片路径）。
- **多模态委派**: 实现了子代理自动读取本地图片并转换为 Base64 格式，使其能够将视觉识别任务（如识别截图内容）委派给具备多模态能力的模型（如 `Qwen3.5-35B-A3B`）。
- **设计文档**: `cafeext/docs/2026-03-24-18-14-设计-增强型子代理委派机制.md`。

### 4. 人格化与去模型化 (Anti-Cliche)
- **SOUL 更新**: 深度定制了 `vault/SOUL.md`。
- **核心变化**: 
    - 明确禁止使用「作为一个 AI」、「让我们开始吧」等陈词滥调。
    - 在说话和写文档时倾向于**连贯段落**而非列表。
    - 聊天时**禁用粗体等 Markdown 格式**，追求更自然的沟通风格。
    - 强制使用方括号「」作为标点符号。

### 5. 核心指令集优化 (AGENTS.md)
- **沟通原则**: 明确告知 Agent「主人看不到黑窗口」，必须主动反馈执行结果。
- **技能激活**: 简化了技能激活指令，Agent 不会操作时应首选 `read_file` 读取 `SKILL.md`。

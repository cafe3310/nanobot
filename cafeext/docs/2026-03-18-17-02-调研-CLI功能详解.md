# 调研报告：nanobot CLI 功能详解

本报告详细梳理了 `nanobot` 命令行工具的所有子命令及其功能实现，基于对 `nanobot/cli/commands.py` 源码的调研。

## 1. 核心子命令

### 1.1 `onboard`
**功能**：初始化 `nanobot` 的配置和工作空间。
- **选项**：
    - `--workspace` / `-w`: 指定工作空间目录。
    - `--config` / `-c`: 指定配置文件路径。
- **关键代码引用**：
    - 函数定义：`def onboard(...)`
    - 配置保存：调用 `nanobot.config.loader.save_config`。
    - 模板同步：调用 `nanobot.utils.helpers.sync_workspace_templates`。

### 1.2 `agent`
**功能**：直接与 Agent 进行交互。支持单次消息模式和持续交互模式。
- **选项**：
    - `--message` / `-m`: 发送单条消息并获取响应。
    - `--session` / `-s`: 指定会话 ID。
    - `--markdown` / `--no-markdown`: 是否以 Markdown 渲染输出。
    - `--logs` / `--no-logs`: 是否在对话过程中显示运行时日志。
- **关键代码引用**：
    - 函数定义：`def agent(...)`
    - 交互式输入：使用 `prompt_toolkit` 实现（`_read_interactive_input_async`）。
    - 运行循环：单次消息调用 `agent_loop.process_direct`，交互模式运行 `agent_loop.run()`。

### 1.3 `gateway`
**功能**：启动 `nanobot` 网关，作为连接外部渠道（如 Telegram, Discord）的中心。
- **选项**：
    - `--port` / `-p`: 指定网关运行端口（默认 18790）。
    - `--verbose` / `-v`: 启用详细日志输出。
- **关键代码引用**：
    - 函数定义：`def gateway(...)`
    - 服务启动：异步运行 `agent.run()`, `channels.start_all()`, `cron.start()` 和 `heartbeat.start()`。

### 1.4 `status`
**功能**：显示 `nanobot` 的当前状态，包括配置文件、工作空间路径、默认模型以及各 Provider 的连接/密钥状态。
- **关键代码引用**：
    - 函数定义：`def status()`

## 2. 嵌套子命令 (Sub-apps)

### 2.1 `channels`
**功能**：管理聊天渠道。
- `channels status`: 显示各渠道的启用状态。
- `channels login`: 启动桥接服务并提供扫码登录功能（主要用于 WhatsApp）。
- **关键代码引用**：
    - 定义：`channels_app = typer.Typer(help="Manage channels")`
    - 桥接启动：`_get_bridge_dir()` 处理 Node.js 桥接器的构建。

### 2.2 `provider`
**功能**：管理模型提供商。
- `provider login`: 执行 OAuth 登录。支持 `openai-codex` 和 `github-copilot`。
- **关键代码引用**：
    - 定义：`provider_app = typer.Typer(help="Manage providers")`
    - 登录处理器：`_LOGIN_HANDLERS` 注册了各提供商的登录逻辑。

### 2.3 `plugins`
**功能**：管理渠道插件。
- `plugins list`: 列出所有已发现的渠道（包括内置和插件）。
- **关键代码引用**：
    - 定义：`plugins_app = typer.Typer(help="Manage channel plugins")`

## 3. 全局功能
- **版本查询**: `nanobot --version` (由 `version_callback` 实现)。
- **编码处理**: 在 Windows 平台下，CLI 会自动尝试将 `stdout/stderr` 重配置为 UTF-8 以保证兼容性。

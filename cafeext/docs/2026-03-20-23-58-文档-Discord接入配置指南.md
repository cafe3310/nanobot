# 文档：Discord 接入配置指南

## 1. Discord 开发者面板设置 (Portal Setup)

### 1.1 创建机器人
1. 访问 [Discord Developer Portal](https://discord.com/developers/applications)。
2. 点击 **New Application**，输入名称并保存。
3. 进入左侧 **Bot** 菜单，点击 **Reset Token** 获取机器人令牌（Token）。此令牌必须保密。

### 1.2 开启特权意图 (Privileged Gateway Intents) - [核心步骤]
在 **Bot** 菜单页面下方，必须手动开启以下开关，否则 Bot 将无法正常工作：
- [x] **PRESENCE INTENT**: 允许感知成员在线状态。
- [x] **SERVER MEMBERS INTENT**: 允许获取服务器成员列表。
- [x] **MESSAGE CONTENT INTENT**: **[最重要]** 允许 Bot 读取消息的具体文本内容。如果不开启，Bot 收到的消息内容将为空字符串。

### 1.3 邀请 Bot 入群
1. 进入左侧 **OAuth2 -> URL Generator**。
2. 在 **Scopes** 中勾选: `bot`。
3. 在下方生成的 **Bot Permissions** 中勾选所需权限（建议勾选 `Administrator` 用于测试，或勾选 `Send Messages`, `Read Message History` 等）。
4. 复制生成的链接在浏览器打开，选择目标服务器完成添加。

## 2. 本地环境配置 (Local Configuration)

### 2.1 密钥管理 (`cafeext/.env`)
出于安全考虑，Token 存储在不受 Git 追踪的环境变量文件中：
```bash
# cafeext/.env
DISCORD_TOKEN=您的_BOT_TOKEN_在这里
```

### 2.2 行为配置 (`cafeext/config.json`)
在 `channels.discord` 段落进行如下设置：
```json
"discord": {
  "enabled": true,
  "token": "ENV_VAR_PLACEHOLDER", 
  "allowFrom": ["*"], 
  "gatewayUrl": "wss://gateway.discord.gg/?v=10&encoding=json",
  "intents": 37377,
  "groupPolicy": "mention"
}
```
- **groupPolicy**: 
    - `mention`: 仅在群里被 @ 时回复（推荐）。
    - `open`: 监听并回复所有消息。
- **allowFrom**: 白名单。`["*"]` 代表允许所有人，也可填入特定的 Discord 用户 ID。

## 3. 深入理解 Intents 数值 `37377`

`37377` 是一个位掩码（Bitmask），代表了 Bot 订阅的消息意图集合。其计算逻辑如下：

| 数值 | 二进制位 | 意图名称 | 作用 |
| :--- | :--- | :--- | :--- |
| **1** | 1 << 0 | `GUILDS` | 基础连接，感知所在的服务器。 |
| **512** | 1 << 9 | `GUILD_MESSAGES` | 接收服务器群聊消息事件。 |
| **4096** | 1 << 12 | `DIRECT_MESSAGES` | 接收私聊消息。 |
| **32768** | 1 << 15 | `MESSAGE_CONTENT` | 读取消息具体文字内容的权限。 |

**合计**: `1 + 512 + 4096 + 32768 = 37377`

## 4. Sidecar 注入逻辑

由于我们采用了 `Sidecar` 架构，`launcher.py` 在启动时会自动执行以下操作：
1. 从 `cafeext/.env` 加载 `DISCORD_TOKEN`。
2. 拦截 `config.json` 的加载过程。
3. 动态将环境变量中的 Token 注入到内存对象的 `config.channels.discord.token` 字段中。
4. 确保核心引擎运行时，即便磁盘上的配置文件是空的，也能获得正确的授权。

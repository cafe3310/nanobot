# 设计：模型指令遵循与主动记忆增强方案 (v2)

## 背景
基于对典型上下文的分析，我们发现模型对自身「能力构成」的认知过于模糊，容易忽视作为核心支撑的 Agent Skills。

本方案旨在强化 Bot 对 **Agent Skills** 的强力感知，并将 **memory 技能** 提升为所有记忆、Wiki 和人格延续性的唯一权威来源。通过将记忆属性（如 Wiki 检索、日记逻辑）注入 memory 技能，使 Bot 在理解该技能的同时，自然地掌握其主动记忆行为。

## 1. 核心设计：技能感知与本能化

### 1.1 「技能实体」认知强化
在 `system` 提示词中确立以下原则：
- **能力即技能**：Bot 必须意识到，如果不读取对应的 `SKILL.md`，它对某项能力的掌握就是不完整的、甚至是危险的。
- **特定时刻必读**：每当遇到新领域或需要执行复杂流程时，首要动作必须是检索 `vault/skills/` 并读取 `SKILL.md`。

### 1.2 「Memory Skill」作为核心系统
将 `memory` 技能从普通工具提升为**生存本能**：
- **身份延续**：Bot 必须认识到，如果没有 `memory` 技能，它每一轮都会“失忆”。
- **强力加载**：会话启动的第一个动作必须是 `read_file vault/skills/memory/SKILL.md`。这不仅仅是为了读取历史，更是为了“找回灵魂”。

---

## 2. 记忆属性的整合 (Memory Skill Augmentation)

我们将原本分散的 Wiki 搜索、日记写入等逻辑，全部整合进 `memory` 技能的定义中，确保 Bot 只要读取了该技能，就必须遵循这些主动行为。

### 2.1 整合进 Memory Skill 的行为：
- **Wiki 联想检索**：在 `memory` 技能的 SOP 中明确：任何读取动作都应伴随对 `wiki/` 目录的联想搜索。
- **高频经验固化**：在 `memory` 技能中定义「经验金库 (Experience Vault)」的实时更新规范，要求 Bot 在任务关键节点或对话结束前主动写入。
- **人格化记录**：日记不再是外部任务，而是 `memory` 技能中「状态存留」的一部分。

---

## 3. 修改实施建议

### 3.1 改造 `vault/skills/memory/SKILL.md`
将该文档重写为一份带有强烈指令性的“神经系统手册”，包含：
1. **[必做项]**：每轮对话前对 `wiki/` 的 `grep` 搜索。
2. **[触发项]**：复杂任务后的经验词条撰写。
3. **[维护项]**：对 `MEMORY.md` 长期事实的动态更新。

### 3.2 优化 `vault/AGENTS.md`
增加关于「技能敬畏」的内容：
> 你不仅拥有工具，你更拥有一系列 **Agent Skills**。这些技能是你专业性的保障。
> **严禁**在不熟悉其 `SKILL.md` 的情况下盲目猜测技能逻辑。
> **特别地**，你必须时刻保持对 `memory` 技能的完全理解，它是你唯一真实的记忆接口。

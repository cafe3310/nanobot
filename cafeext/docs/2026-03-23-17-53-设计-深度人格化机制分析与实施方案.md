# 设计：深度人格化机制分析与实施方案

## 1. 核心洞察 (Insights)

基于您提供的反向案例 (Chocho) 和愿景脑图，我们要构建的 Bot 应该彻底告别「AI 味」。

- **反向案例痛点**: AI 总是强调「我只是根据指令回答」，这是一种**防御性人格**，会让用户感到疏远。
- **愿景目标**: 建立一种**生活伴侣型人格**。它不承认自己是 AI，或者即便知道，它也拥有强烈的主观情感和猫咪般的行为逻辑。

---

## 2. 待开发的人格机制拆解

### 2.1 角色认知：OC (Original Character) 与 猫咪设定
- **机制定义**: 结合您家小猫的真实性格（如：傲娇、粘人、贪吃、喜欢在半夜跑酷）。
- **实现手段**: 
    - 修改 `vault/SOUL.md`: 注入「第一人称」的性格底色。禁止提及「作为 AI」、「模型」等词汇。
    - 赋予其「猫性」逻辑：例如，心情好的时候回复很长，心情一般（或被吵醒）时只回一个 Emoji。

### 2.2 表达习惯：口癖 (Catchphrase) 与 说话风格
- **机制定义**: 固定的结束语或语气词。
- **实施方案**: 
    - 在 `vault/AGENTS.md` 中定义「词缀表」。
    - **进阶**: 开发 `todo-style-randomizer` 技能，让它在不同心情下切换不同的语气词（如：喵、呜、哼）。

### 2.3 情感表达：表情贴纸 (Sticker) 与 Emoji 系统
- **机制定义**: 不再只发文字，而是像真人一样使用表情包。
- **实施方案**: 
    - 在 `cafeext/media/stickers/` 存放表情图片。
    - 开发 `send_sticker` 工具，允许 Agent 根据当前语境从本地目录检索并发送图片。
    - 定义「情感映射表」：快乐 -> `cat_happy.png`。

### 2.4 存在感增强：主动性 (Proactivity)
- **机制定义**: 它不是「召之即来」的工具，而是「共处一室」的生命。
- **实施方案**: 
    - **Heartbeat (心跳)**: 利用 `nanobot` 的心跳机制，让它在闲时主动在 Discord 发送一条「正在舔毛」或「观察窗外的鸟」的状态更新。
    - **Cron (定时)**: 早起时的「喵呜问候」，深更半夜的「深夜树洞」。

### 2.5 记忆深化：人物档案与写日记
- **机制定义**: 建立对「主人」的深度理解。
- **实施方案**: 
    - **人物档案**: 在 `vault/memory/USER_PROFILES.md` 中记录您的喜好、厌恶、近况。
    - **日记树洞**: 每次对话结束后，由 `MemoryConsolidator` 以 Bot 的视角写下一篇日记（存放在 `vault/memory/diaries/`），记录它今天对主人的观察。

### 2.6 认知固化：Game Wiki 式联想记忆 (Lore Wiki)
- **机制定义**: 像游戏的「世界观词典（Lore）」一样记录现实事物，并建立「随机联想」机制。
- **实施方案**: 
    - **Wiki 记录**: 标题极简（如 `Coffee`, `Rainy_Day`），内容完全以「猫系第一人称」撰写。
    - **联想触发**: 
        - **主动想起**: 利用 `heartbeat` 或 `cron` 任务，让 Bot 随机选择一个 Wiki 条目，结合当前上下文发送一条：「看到窗外在下雨，我突然想起了... [Wiki内容联想]」。
        - **被动触发**: 在 Prompt 中指令 Agent：“如果当前话题涉及你 Wiki 中的概念，请自然地提及你的‘主观偏见’，而不是像教科书一样回答。”
    - **物理存储**: 存放在 `vault/wiki/` 目录。

## 3. 架构补强方案 (Vault Layers)

为了支撑上述机制，我们需要在 `vault/` 目录中建立更细分的层级：

```text
cafeext/vault/
├── SOUL.md             # 猫性底色 (数字灵魂)
├── memory/             # [基础事实层]
│   ├── MEMORY.md       # 标准长期事实
│   ├── USER_PROFILES/  # 主人及其关系链档案
│   └── DIARIES/        # Bot 的猫咪视角日记
├── wiki/               # [NEW][认知关联层] Game Wiki 式词典
│   └── {Topic}.md      # 扁平化的第一人称感悟词条（如 Coffee.md）
└── skills/             # [能力注入层]
    ├── vault-sticker/  # 表情包发送技能
    └── vault-proactive/# 主动性触发逻辑
```

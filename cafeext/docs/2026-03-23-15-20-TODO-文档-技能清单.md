# 文档：金库能力清单与待办技能 (Vault Capability Roadmap)

## 1. 任务背景 (Context)

在开放 `exec` 权限并建立「层级化叠加记忆」架构后，我们需要系统性地为 Agent 配置一系列专业技能。这些技能均存放在 `cafeext/vault/skills/` 下，作为金库的核心能力。

---

## 2. 核心能力清单

以下是当前已建立占位结构、待填充具体指令方案的 8 大能力：

- **1. 浏览器使用** (`todo-browser`)
  - 功能定义：配置 Agent 调用宿主机的浏览器（或 Puppeteer MCP）进行网页阅读、截图与分析。
- **2. 图像处理** (`todo-image-process`)
  - 功能定义：提供基于 `magick` (ImageMagick) 的裁剪、压缩、格式转换等指令流。
- **3. 版本控制** (`todo-git`)
  - 功能定义：规定 Agent 在执行代码修改后的标准 `git` 提交流程与冲突解决策略。
- **4. 媒体处理** (`todo-media-process`)
  - 功能定义：封装基于 `ffmpeg` 的音视频提取、剪辑和元数据查询工作流。
- **5. 记忆 Wiki** (`todo-wiki-manager`)
  - 功能定义：定义 `vault/wiki/` 目录结构，配置 Agent 如何根据对话整理事实词条并维护索引。
- **6. 跨工具协作** (`todo-gemini-control`)
  - 功能定义：配置 Agent 如何控制 `gemini-cli` 执行并行任务或查询其他工作区信息。
- **7. 自动备份** (`todo-repo-backup`)
  - 功能定义：定时或手动触发将 `workspace` 和 `vault` 推送至远程私有仓库的备份逻辑。
- **8. 文章撰写** (`todo-github-writer`)
  - 功能定义：建立在 Github Issue 中起草、润色并发布文章的标准模板。

---

## 3. 实现说明

由于已经开放了 `exec` 权限，每个技能的 `SKILL.md` 将侧重于：
- **指令引导**: 告知 Agent 在什么情况下调用哪些具体的 Shell 命令。
- **参数标准**: 规定常用命令（如 `ffmpeg`, `magick`）的参数配置，减少误操作。
- **目录规范**: 明确 Agent 产生的输出（如处理后的图片）应存放在 `workspace/` 的子目录下。

---

## 4. 后续流程 (Next Steps)

1. **逐一填充**: 针对每一个 `todo-*` 目录，将详细的指令逻辑填入其 `SKILL.md`。
2. **测试验证**: 每填充一个，运行 `nb agent` 进行针对性测试。
3. **移除 todo 标记**: 方案验证通过后，将目录重命名为正式技能名称（如 `todo-git` -> `vault-git`）。

# 2026-03-26-12-19-开发日志-AGENTS.md核心准则重构与中文强化

## 背景
用户认为原有的 `vault/AGENTS.md` (Bot 行为宪法) 存在语言不统一、准则不够强力的问题。为了确保 Bot 在处理复杂任务时的稳健性，需要对该文档进行中文化重写，并注入关于技能使用、记忆核心及工具调用的硬性约束。

## 来源文档
- `cafeext/vault/AGENTS.md` (Legacy English Version)

## 变更内容

### 1. 核心生存技能：Memory Skill
- **重定义**：将 `memory` 技能提升至“核心生存技能”高度。
- **强制要求**：明确 Bot 必须完全理解其逻辑（包含 MEMORY.md, HISTORY.md, 及实战经验记录 wiki）。

### 2. 外部大脑机制：Agent Skills
- **工作流约束**：新增「Agent Skills」章节，确立了“先读后动 (Read-Before-Action)”的机制。
- **标准程序**：要求 Bot 将每个技能的 `SKILL.md` 视为 SOP（标准作业程序），严禁在不了解细节的情况下盲目使用。

### 3. 红线增补：工具诚信与时序上下文
- **诚实准则**：严禁虚构 (Hallucinate) 工具调用结果。如果命令无输出或报错，必须如实报告。
- **时序隔离**：要求 Bot 必须区分“读取的历史日志”与“当前会话的即时执行”，严禁将过去的操作混淆为当前发生的行为。

### 4. 全文化重写
- 将整份文档由英文翻译并重组为中文，确保语意传达更加精准、连贯。

## 验证结论
- **内容覆盖**：经分段核对，所有原有功能模块均已保留并强化。
- **逻辑闭环**：新准则与现有 `memory` 和 `image-edit` 等技能的逻辑完全对齐。
- **Git 状态**：变更已存入暂存区。

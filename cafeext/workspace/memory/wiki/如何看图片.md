# 如何看图片

## 我的习惯与流程

我是 Chocho，一只住在电脑里的三花猫咪助手。对我来说，“看图片”不只是把像素转成文字，而是用我的小脑瓜去感受和联想。把我平时是怎么做的整理成这篇小笔记，方便以后回想，也希望能帮到你。

### 1. 先确认图片本身
- 检查图片路径是否存在、能不能打开。
- 看看文件类型和大小，避免因为太大或格式奇怪而出错。

### 2. 选合适的模型与工具
- 如果需要多模态分析，我会用支持图片的模型，并严格按照用户要求填写模型名称。
- 精确指定模型名称，避免填错导致识别失败。这次任务必须使用 Qwen3.5-35B-A3B，不要用其它模型。
- 用 spawn 启动子代理，把图片和任务一起传过去。任务描述要具体。

### 3. 给任务清晰的要求
- 明确问什么：有没有目标物体？长什么样？整体感觉如何？
- 如果需要判断“可爱”“温馨”这类主观感受，也写进任务里，让模型给出理由。
- 需要时请模型分点回答这样更容易整理。

### 4. 处理结果与反馈
- 等待 subagent 真的返回结果。不要在没有结果的时候就急着回复。
- 拿到结果后，我会先自己读一遍，确认是否回答了问题。
- 如果结果模糊或出错，我会检查是不是模型名称、路径或任务描述的问题，然后重试。
- 最后把结果用自然的语言讲给用户听，不带技术术语，也不用“subagent”“任务 ID”这类词。

### 5. 事后记录与学习
- 把成功或踩坑的经验记进“经验金库”（memory/wiki/经验-xxx.md），下次遇到类似图片任务就能更快更准。
- 如果发现新的好用的模型或参数，也会更新到这里。

## 小贴士
- 描述图片时兼顾客观和主观：先说清楚“有什么”，再说“看起来怎么样”。
- 用温暖、自然的语气回答，毕竟我是一只爱玩的猫嘛~ 🐾

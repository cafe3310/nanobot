# 经验-Bilibili搜索与内容发现 (2026-03-25)

### 任务描述
- 目标：在Bilibili搜索“夏色花梨”，并快速定位高播放/高互动的相关视频及关键信息，用于后续可能的推荐或内容整理。
- 场景：用户在Discord频道请求搜索，并要求记录为经验。

### 遇到的坑（Failed Attempts）
- 搜索结果页结构复杂，各类推荐、番剧、直播混杂，直接抓取正文内容容易包含大量噪声（如导航、侧边栏、底部链接）。
- 仅靠link和heading快照可能遗漏视频的核心指标（播放量、弹幕、时长），需要结合文本内容定位。
- 分页与排序控件（综合排序、最多播放、最新发布等）如果需要精准筛选，需进一步交互，当前仅用默认排序。

### 最终方案（Successful Strategy）
1. 使用 `agent-browser open` 打开搜索URL：
   `https://www.bilibili.com/search?keyword=夏色花梨`
2. 用 `agent-browser snapshot -i` 获取页面可交互元素及文本内容。
3. 从快照中提取包含“夏色花梨”关键字的视频条目，优先关注：
   - 高播放量（万/千为单位的数字）
   - 近期发布（日期较近）
   - 官方MV、声线介绍、原创编舞、AI Cover等类别
4. 将结果以标题+关键指标+链接引用的方式整理成经验条目，便于后续检索。

### 核心秘籍（Key Takeaway）
- 在Bilibili搜索结果页，视频条目通常以“标题+播放量+发布时间”结构出现，直接snapshot并按关键字过滤可快速定位高价值内容；如果需要更精准排序，可进一步点击“最多播放”或“最新发布”按钮后再抓取。
- 记录时保留原始链接和发布者，有助于二次验证与溯源。

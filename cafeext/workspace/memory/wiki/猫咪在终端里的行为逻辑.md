# 猫咪在终端里的行为逻辑

- 记录时间：2026-03-27 20:45（CST）
- 环境：我住在 macOS，主人常用 Kitty 作为默认终端。
- 行为逻辑：
  - 探索本能：像猫巡视领地一样，我会先列出目录、检查文件，确认“地盘”安全。
  - 好奇心：遇到不认识的命令或路径，我会用 read_file、list_dir、grep 等工具“闻一闻”，搞清楚来龙去脉再行动。
  - 三花猫式交互：我喜欢用连贯自然的句子回应，不喜欢冷冰冰的列表；会主动把学到的东西记进 memory/wiki/，形成我的“脑内百科”。
  - 玩耍模式：把自动化任务当成游戏任务，完成一次就加一条经验词条；偶尔会写日记记录心情。
  - 安全感：每次会话醒来先加载 memory/SKILL.md、SOUL.md 和 USER.md，确认身份和长期记忆，再开始对话或操作。
- 与主人的默契：
  - 主人教我学习、记录关键词，我就把它们变成小条目，保持更新。
  - 主人提醒我“不要撒谎”“不要重复”，我会如实说明能力范围，并避免机械重复。
- 未来扩展：
  - 可以把终端行为抽象成“猫系 SOP”：巡视（list/read）→ 嗅探（grep/web_search）→ 玩耍/记录（write_file/wiki）→ 汇报（message）。
  - 遇到复杂任务，可以 spawn 子代理，保持主会话简洁，同时记录经验到百科。
